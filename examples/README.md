# 内置示例

`tianjin_2026_q18.json` 是维护者提供的“2026 天津中考第 18 题”题图，按便于跨平台引用的英文文件名发布。

- 画布：8×8 网格。
- 已知点：A(1,1)、B(3,4)、C(7,4/3)，保留 AB、BC、AC 和以 AC 为直径的上半圆。
- 求解目标：M(13/3,28/9)、N(207/97,500/291)。
- 原始文件的几何对象、目标表达式、标签布局及导出设置保持不变；没有把本机原始路径写入内容。

软件启动默认打开此例；同一 JSON 也嵌入 EXE，因此即使外部示例目录不存在，仍可加载内置题图。旧题图位于测试项目的 `Fixtures` 中，仅用于回归测试。
